Lane V implementation: reactive `value` cell primitive with read/write/reset/subscribe, computed derivation via `value([deps], fn)`, immutable key operations with dot-delimited deep paths (leaf+ancestor firing, silent equal-value no-op), and a callable-as-hook React bridge. Also authored the utils branding contract types (type-only entry `src/utils/index.ts`) per workplan_utils.md so every value/computed instance carries its inner data type for wrapper-transparent inference (ADR-0003). Tests derived test-first from scenarios V1–V15 plus branding witnesses; all four gates green in the lane worktree.

What changed and why: the notification design is one shared core (`src/value/core.ts`) holding whole-value listeners and key-targeted subscriptions, where each key subscription caches the value at its path and fires only when a state change moves that value — this single mechanism gives change-only delivery, attach silence, ancestor-identity churn firing on deep writes, and sibling silence for free, instead of per-path bookkeeping scattered across the module. Deep-path writes (`src/value/paths.ts`) propagate an equal-leaf check upward so an equal-value write is a total no-op: no notification and no new references anywhere (V13's last steps pinned this). Missing intermediates are created and primitives met mid-path are replaced by containers on write (V14); missing-path reads walk to `undefined` without throwing (V12). Mutable and computed cells share the read surface assembly and the hook bridge (`useSyncExternalStore`); the computed cell simply omits write members, so V7's "compile-time failure" holds through the type-level absence of `set`/`setKey`/`reset` on `ComputedCell` — pinned with per-statement `@ts-expect-error` witnesses executed by the typecheck gate, plus runtime absence assertions.

Notes for the orchestrator: (1) the committed package-lock.json carries no rolldown native bindings (vitest 5 chain), so a plain `npm install` on linux-x64 fails at vitest startup with "Cannot find native binding" — this lane fixed its worktree with `npm install --no-save @rolldown/binding-linux-x64-gnu@1.2.13` and deliberately did NOT regenerate the shared lockfile; a lockfile repair deserves its own deliberate change. (2) `@paker/value` cannot yet re-export `InferValue` as its API table lists: per instructions this lane authored only the branding contract in utils, not the Infer* helpers; the utils lane adds the re-export line when the helpers land. Branding witnesses live locally in `src/value/branding.test.ts` as conditional-type readers over `Brand<TData>` until then. (3) Literal-dot keys are unreachable via path form as pinned — `getKey("a.b")` is always the two-segment path; no runtime API distinguishes path form from direct form for strings, so the parenthetical in the parent decision about a "direct one-level key form" for dotted keys has no observable behavior in this lane's contract.
